## Run Locally

Because the PWAs use service workers, run the project through a local HTTP server rather than opening the files directly with `file://`.

From the repository root:

```bash
python -m http.server 8000
```

Then open:

- `http://localhost:8000/portfolio/`
- `http://localhost:8000/pwa-business-quickquote/`
- `http://localhost:8000/pwa-booking-enquiry/`

## GitHub Pages

The repository can be published using GitHub Pages.

If the repository is configured to serve from the root, the portfolio can be accessed through the repository's GitHub Pages URL.

If the portfolio remains inside the `portfolio/` directory, configure the deployment structure accordingly or move the contents of `portfolio/` to the repository root if the portfolio is intended to be the primary website.

Before publishing, verify that:

- Relative links work correctly
- CSS and JavaScript files load correctly
- Images and assets load correctly
- PWA service workers use the correct paths
- WhatsApp links work
- Email links work
- GitHub and LinkedIn links point to the correct profiles

## Important Honesty Rule

The portfolio distinguishes between **demonstrations** and **services**.

### Working Demonstration

Items labelled as **WORKING DEMO** are functioning projects or demonstrations that can be explored.

### Service

Items labelled as **SERVICE** describe capabilities that HAIVEXA can offer to clients.

A service should **not** be presented as completed client work unless it has actually been delivered to a client.

This keeps the portfolio accurate, transparent and trustworthy.
